# 아이템 프로토타입 브랜치 인수인계 가이드

## 1) 브랜치 목표
- 목표: 아이템 프로토타입 제작
- 입력: 키보드 상단 숫자키 `1~7`
- 제외: 손에 들고 휘두르는 무기(사무용 도구) 프로토타입은 이번 범위에서 제외
- UI 요구: 화면 우측에 `키 번호 -> 아이템` 매핑 표기

---

## 2) 현재 확정된 게임 규칙
- 인벤토리 개념 없이, 모든 아이템은 손에 들고 사용
- 한 번에 손에 들 수 있는 아이템은 1개
- 기절 시 손에 든 아이템은 즉시 드랍
- 화염 방사기는 손에 들고 최대 5초만 사용
- 소모형 아이템은 발동 시 즉시 소모

---

## 3) 현재 코드 반영 내역
- 추가된 핵심 스크립트:
  - `Assets/_Project/Scripts/Game/ItemPrototypeHotkeyRunner.cs`
- 주요 기능:
  - `1`: 블랙홀 폭탄 프로토타입
  - `2`: 커지는 아이템 프로토타입
  - `3`: 작아지는 아이템 프로토타입
  - `4`: 아이스 아메리카노(슈퍼아머) 프로토타입
  - `5`: 화염 방사기(토글, 최대 5초)
  - `6`: 투명화 아이템 프로토타입
  - `7`: 위성 폭격 프로토타입
  - `0`: 기절 드랍 시뮬레이션(프로토타입 검증용)
- 우측 OnGUI 패널로 키 매핑/상태 표시 구현됨
- 런타임 자동 부트스트랩(`RuntimeInitializeOnLoadMethod`) 방식이라 씬에 수동 배치 없이 동작

---

## 4) 테스트 방법(다음 세션 시작 시)
1. Unity Play 모드 실행
2. 화면 우측 패널 표시 확인
3. `1~7` 키로 각 효과 확인
4. `5` 실행 후 5초 자동 종료 확인
5. `0` 키로 장비형 드랍(프로토타입 상 화방 해제) 확인

---

## 5) 현재 상태에서 미확인/보완 필요
- MCP for Unity 연결이 이 세션에서는 리소스로 인식되지 않았음 (`resources: []`)
- 실제 플레이어 컨트롤러/네트워크 객체와 완전 연동 검증은 미진행
- 데이터 테이블(`ItemTable`, `SoundAssetTable`, `VfxAssetTable`, `ItemPresentationTable`)은
  현재 워크스페이스에서 파일 위치가 확인되지 않음
- 위 CSV 파일들이 실제로 이동된 경로를 다음 세션 초기에 재확인 필요
