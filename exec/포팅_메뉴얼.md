## 사전 준비

### 1. Unity Hub 설치

[Unity Hub 다운로드](https://unity.com/download) 후 설치

### 2. Unity 2022.3.62f1 설치

Unity Hub에서 `Installs > Add > Archive` 또는 직접 버전 검색으로 **2022.3.62f1 LTS** 설치

빌드 모듈 추가 (필요 시):
- Windows Build Support (IL2CPP)
- Mac Build Support (IL2CPP)
- Linux Build Support (IL2CPP)

### 3. Git 설치 및 프로젝트 클론

```bash
git clone https://lab.ssafy.com/s14-metaverse-game-sub1/S14P21D104.git
```

클론 후 Unity 프로젝트 경로: `S14P21D104/client`

## 프로젝트 설정

### 1. Unity Hub에서 프로젝트 열기

1. Unity Hub 실행
2. `Projects > Open > Add project from disk`
3. `S14P21D104/client` 폴더 선택
4. 버전이 **2022.3.62f1**인지 확인 후 열기

### 2. 패키지 임포트 대기

프로젝트를 처음 열면 Unity가 아래 작업을 자동으로 수행합니다:

- `Library/` 캐시 생성 (수 분 소요)
- Packages/manifest.json 기반 패키지 다운로드 및 임포트
- URP, TextMeshPro Essential Resources 임포트 팝업 발생 시 **Import** 클릭

### 3. 레이어 설정 확인

`Assets/Editor/GrabLayerSetup.cs`, `GrabSystemSetup.cs`는 에디터 초기화 시 자동 실행됩니다.
레이어 충돌 오류가 발생하면 `Edit > Project Settings > Physics` 레이어 매트릭스를 확인합니다.

## Photon Fusion 설정

### Photon App ID 확인

설정 파일 위치:
```
Assets/Photon/Fusion/Resources/PhotonAppSettings.asset
```

| 항목 | 값 |
|------|----|
| AppId Fusion | c1b82806-ebed-4912-9ed1-cbd8af78e727 |
| App Version | ssafy-playtime-v1 |
| Region | kr (한국) |
| Protocol | UDP |

> App ID는 [Photon 대시보드](https://dashboard.photonengine.com)에서 발급받은 값입니다.
> 새 프로젝트로 포팅 시 대시보드에서 새 App ID를 발급받아 위 파일에서 교체합니다.

### Fusion SDK 확인

`Assets/Photon/Fusion/` 폴더가 존재하는지 확인합니다.
없으면 [Photon Fusion SDK](https://doc.photonengine.com/fusion/current/getting-started/sdk-download)를 다운로드하여 임포트합니다.

## 빌드 및 실행

### 에디터에서 실행 (개발용)

1. Project 창에서 `Assets/_Project/Scenes/LauncherScene.unity` 열기
2. 상단 **Play** 버튼 클릭
3. 로비 → 방 생성 또는 참가 → GameScene 진행

### 빌드 (배포용)

1. `File > Build Settings` 열기
2. 빌드에 포함된 씬 확인:

| 인덱스 | 씬 경로 |
|-------|---------|
| 0 | `Assets/_Project/Scenes/LauncherScene.unity` |
| 1 | `Assets/_Project/Scenes/GameScene.unity` |

3. 플랫폼 선택 후 **Switch Platform**
4. **Build** 또는 **Build And Run** 클릭

### IL2CPP 백엔드 사용 시

`Edit > Project Settings > Player > Other Settings > Scripting Backend`를 **IL2CPP**로 설정하면 빌드 전 Visual C++ (Windows) 또는 Xcode (Mac)가 필요합니다.
